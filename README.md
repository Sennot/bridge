# Bot CPS Bridge

Standalone Geode compatibility layer for MegaHack CPS hold visuals during macro playback.

Target:
- Geometry Dash 2.2081
- Geode 5.8.2
- MegaHack package ID: `absolllute.hackmega`
- Designed to be bot-agnostic; reference targets include SiliFork and xdBot 2.7.6.

The mod never sends synthetic gameplay clicks. It only observes player/button state and adjusts the visible CPS status presentation.
